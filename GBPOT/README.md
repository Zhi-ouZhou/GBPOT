# GBPOT source code

Implementation accompanying **Partial Order Topology Helps in Multi-view Contrastive Clustering with Granular-ball**.

See the [repository README](../README.md) for the method overview, reported results, installation, data preparation, and the single-configuration training command.

Run training commands from this directory so that relative configuration and data paths resolve correctly. The `main.py` parameter-search entry point is unfinished; the repository README documents how to call the existing `run_on_setting` function directly.
